# doit：看目前任務狀態

只讀。不改任務檔、不改程式碼、不接著做任務。回報一律繁體中文。

1. 執行 `node "${CLAUDE_PLUGIN_ROOT}/tools/log.js" --show`。
   - 回「無進行中任務」：告訴使用者目前沒有任務，可以用 `/doit:go <開發指令>` 開始。結束。
2. 讀輸出最後一行「檔案」指向的任務檔，找到最新一版 `## 計畫 vN` 的驗收標準表，以及「## 紀錄」裡的 `[證據 標準N]`、`[審查 …]`、`[錯誤 …]`、`[範圍外]` 行。
3. 用以下格式回報，每欄一兩行：

```
📊 doit 任務狀態：<任務檔名>

- **狀態**：<狀態>（等級 <等級>，命中條件：<命中條件>）
- **分支**：<分支>（起始 SHA <前 7 碼>）
- **下一步**：<下一步>
- **驗收標準**：<已有證據的條數>／<總條數>；缺證據的：<編號，或「無」>
- **審查**：<最後一筆各審查者的結論，或「尚未審查」>
- **問題**：<[錯誤] 的條數與最近一條摘要，或「無」>
- **接續**：狀態不是「完成」「中止」時寫「輸入 /doit:resume 繼續」
```

計畫版本是 0（還沒寫計畫）時，驗收標準那欄寫「尚未寫計畫」。
