# doit：看目前任務狀態

只讀。不改任務檔、不改程式碼、不接著做任務。回報一律繁體中文。

1. 執行 `node "${CLAUDE_PLUGIN_ROOT}/tools/log.js" --show`。
   - 回「無進行中任務」：任務卡片改成一行「目前沒有進行中的任務，可以用 `/doit:go <開發指令>` 開始」，跳到第 5 步。
2. 讀輸出最後一行「檔案」指向的任務檔，找到最新一版 `## 計畫 vN` 的驗收標準表，以及「## 紀錄」裡的 `[證據 標準N]`、`[審查 …]`、`[錯誤 …]`、`[範圍外]` 行。
3. 執行 `node "${CLAUDE_PLUGIN_ROOT}/tools/log.js" --timing`，取它的輸出填「耗時」欄。
4. 用以下格式回報，每欄一兩行：

```
📊 doit 任務狀態：<任務檔名>

- **狀態**：<狀態>（等級 <等級>，命中條件：<命中條件>）
- **分支**：<分支>（起始 SHA <前 7 碼>）
- **下一步**：<下一步>
- **驗收標準**：<已有證據的條數>／<總條數>；缺證據的：<編號，或「無」>
- **審查**：<最後一筆各審查者的結論，或「尚未審查」>
- **耗時**：<總時間與 agent／等使用者的拆分>；最久的階段：<階段與時間>；有步驟耗時時列出最久的一步
- **問題**：<[錯誤] 的條數與最近一條摘要，或「無」>
- **接續**：狀態不是「完成」「中止」時寫「輸入 /doit:resume 繼續」
```

計畫版本是 0（還沒寫計畫）時，驗收標準那欄寫「尚未寫計畫」。

5. **計畫檔進度**：列出 `.doit/plans/` 下頂端「狀態」不是「完成」的計畫檔，讀各自「## 任務清單」的表格，接在任務卡片後面輸出；沒有這種計畫檔就整段省略：

```
🗂️ 計畫：<計畫檔名>（<完成數>／<任務數> 完成）
- T1 <任務> — 完成
- T2 <任務> — 進行中（就是目前的任務時標「← 目前」）
- T3 <任務> — 待開始，依賴 T2
- **下一個可做**：<依賴都已完成、狀態是待開始的第一個任務，附它的「指令」欄內容；沒有寫「無」>
```

使用者問「哪個階段最慢」或要看所有任務的耗時時，改跑 `log.js --timing --all`，回報它最後的「合計」與「各階段由多到少」兩行。耗時是從紀錄行時間戳算的：記的是 agent 寫紀錄的時間，階段邊界有誤差；舊任務檔只到分鐘。
